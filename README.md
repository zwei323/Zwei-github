# Portofolio Zwei Maun Ramadhan

Website portofolio sederhana yang dibuat dengan HTML, CSS, dan JavaScript dan dapat dipublikasikan melalui GitHub Pages.

## File
- `index.html` — struktur halaman
- `style.css` — tampilan dan layout responsif
- `script.js` — menu seluler, navigasi aktif, tahun otomatis, dan tombol kembali ke atas

## Publikasi
Di repository GitHub, buka **Settings → Pages**, pilih **Deploy from a branch**, pilih branch `main` dan folder `/(root)`, lalu klik **Save**.
